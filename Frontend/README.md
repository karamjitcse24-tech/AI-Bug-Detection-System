# AI Bug Detection System

An AI-powered Bug Detection and Management System designed to help users report, analyze, manage, and track software bugs efficiently.

## 🚀 Features

- Add new bugs with title, description, severity, and status
- AI-powered bug analysis
- Automatic bug severity detection
- Recommended actions for reported bugs
- Update existing bugs
- Track bug status
- Dashboard with bug statistics
- Bug severity distribution chart
- Open and closed bug tracking
- Search and filter bugs

## 🛠️ Technologies Used

### Frontend
- React
- Vite
- JavaScript
- CSS

### Backend
- Java
- Spring Boot
- Spring Data JPA
- REST API

### Database
- MySQL

## 📊 Dashboard

The dashboard provides:

- Total Bugs
- Open Bugs
- Closed Bugs
- High Severity Bugs
- Bug Severity Analysis
- Bug Status Analysis

## 🤖 AI Bug Analysis

The system analyzes the bug description and provides:

- Detected Severity
- Reason for the detected severity
- Recommended action to resolve the issue
